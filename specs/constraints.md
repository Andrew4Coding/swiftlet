# Constraints (all targets)

Hard rules for every target. Change them only through an ADR in `decisions/`.

## Technology

- SwiftUI and SwiftData. Persistence syncs through CloudKit.
- CloudKit constraints apply to every model: all attributes have defaults or are optional, and every relationship is optional with an inverse.
- Architecture: `@Observable` view models, stateless helpers in `Services/`, views grouped by feature folder (see `CLAUDE.md`).
- Minimum OS: iOS 26.5; macOS 26.0 for the Mac app (ADR 0002). Code in `Shared/` builds for both.
- The Xcode project is generated by XcodeGen from `project.yml`. Run `xcodegen generate` after adding or removing files.
- `SwiftletWidgets` compiles some app files directly, so those files stay free of app-only dependencies.
- No third-party dependencies without an ADR covering license, privacy manifest and maintenance.

## Privacy

- Financial data stays in the user's own SwiftData store and their private CloudKit database. No third-party analytics, ads or tracking SDKs without an ADR.
- `Swiftlet/PrivacyInfo.xcprivacy` stays accurate for every API used.

## Accessibility

- Dynamic Type up to the largest accessibility sizes, without truncating amounts.
- VoiceOver labels on every interactive element. Never convey income versus expense by colour alone.
- Respect Reduce Motion and Reduce Transparency. Touch targets are at least 44×44 pt.

## Localization and money

- Currency is Indonesian Rupiah only, for example `Rp20.000`. Amounts are never floating point where precision matters.
- User-facing strings go in `Localizable.xcstrings`.

## Quality gates

- The `Swiftlet` scheme builds with no new warnings.
- Every acceptance criterion in an implemented spec has a test, or a documented manual check while there is no test target.
