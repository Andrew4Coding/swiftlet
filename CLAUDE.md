## Project overview

`Swiftlet` is a SwiftUI personal-finance tracker (Indonesian Rupiah only) backed by SwiftData with CloudKit sync, plus a share extension and a WidgetKit extension.

- Bundle identifier: `com.andrew4coding.swiftlet.Swiftlet`
- Deployment target: iOS 26.5
- The Xcode project is generated by XcodeGen from `project.yml` (`Swiftlet.xcodeproj` is git-ignored). Run `xcodegen generate` after adding or removing files.

## Architecture

- `Swiftlet/Models` — SwiftData models: `Transaction` (expense / income / transfer), `TransactionCategory` (emoji + colour, needs/wants/savings purpose, monthly budget), `Wallet` (user-defined, balance derived from transactions), `RecurringTransaction`. `MoneySource` is the legacy fixed wallet list, kept only so `WalletMigrator` can link old transactions.
- CloudKit constraints apply to every model: all attributes need defaults or optionals, and every relationship must be optional with an inverse.
- `Swiftlet/Services` — stateless helpers: category seeding and icon suggestion (Foundation Models, with a keyword fallback), wallet migration, budget and insight calculation, recurring scheduling and reminders, import/export.
- `Swiftlet/ViewModels` — `@Observable` view models.
- `Swiftlet/Views` — feature folders (Home, Add, Transactions, Wallet, Budget, Recurring, Account) plus shared `Components` (`AppTheme`, `FormField`, badges).
- `SwiftletWidgets` compiles a few app files directly (see `project.yml`), so keep those free of app-only dependencies.

Launch and foreground work runs in `SwiftletApp.refreshBackgroundWork()`: wallet migration, then recurring materialization, then reminder rescheduling.

## Common commands

```bash
xcodegen generate
xcodebuild -project Swiftlet.xcodeproj -scheme Swiftlet -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```
